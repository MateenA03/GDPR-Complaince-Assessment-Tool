# GDPR-Compliance-Asessment-Tool
GDPR Compliance Asessment Tool 

This Web Application is a simple, effective tool built to help organisations quickly assess their GDPR compliance, with a focus on Articles 5 and 6.  
It guides users through a structured, multi-step form designed to capture real insights — not just tick boxes.  
Once completed, it generates a polished PDF compliance report, automatically emails the report to the user and admin, and saves every submission securely for future audits or reviews.

## Features

- Step-by-step GDPR self-assessment covering core principles and lawful processing
- Instantly generate a professional, downloadable PDF report
- Automatic email delivery to both user and admin
- Visual compliance summary with charts for quick insights
- Secure logging of all submissions in one central file
- Built specifically around GDPR Articles 5 (Data Principles) and 6 (Lawfulness)

## Purpose

Compliance shouldn’t be complicated or overwhelming.  
This tool makes it easy for organisations to check themselves, document compliance, and take action where needed — all without endless paperwork or consultancy fees.  
Whether you're preparing for an audit, improving internal policies, or just want peace of mind, this tool gives you the confidence and documentation to prove you’re on track.

Smart compliance. Zero stress.
